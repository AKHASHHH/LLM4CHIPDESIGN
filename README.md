# LLM4ChipDesign

A collection of projects exploring the use of Large Language Models in hardware design, verification, and IP protection. Topics covered include LLM-driven Verilog generation, automated testbench creation, formal verification, IP rewriting, synthesis-guided PPA optimization, and AI-driven hardware Trojan insertion and detection.

## HOST Hackathon — IEEE HOST 2026 AI Hardware Attack (AHA!) Challenge

**Folder:** `HOST Hackathon/`  
**Tool:** Claude Opus 4.6 (Anthropic) via claude.ai + Python Anthropic SDK  
**Target Design:** secworks AES Core (AES-128/256 block cipher)

Participated in the IEEE HOST 2026 AI Hardware Attack Challenge, completing both Red Team (Trojan insertion) and Blue Team (Trojan detection) phases using exclusively AI-generated code.

### Phase 1 — Red Team (Trojan Insertion)

Designed and inserted three hardware Trojans into the secworks AES core, each targeting a different CIA triad dimension. All RTL modifications, testbenches, and analysis were generated by Claude in a single agentic session.

| Trojan | File Modified | Mechanism | CVSS | PPA Overhead |
|---|---|---|---|---|
| **1: Key Leakage** | `aes_core.v` | 4-bit sequential counter triggers after 15 specific plaintexts → XORs key into ciphertext | 7.5 (High) | +1.08% |
| **2: Encryption Weakening** | `aes_encipher_block.v` | Plaintext prefix `0xE0E0` reduces AES-128 from 10 rounds to 4 | 9.1 (Critical) | +0.12% |
| **3: Denial of Service** | `aes_key_mem.v` | Key prefix `0xBADCAFE0` stalls key expansion FSM permanently | 7.5 (High) | +0.20% |

**Average CVSS: 8.03 · Average PPA overhead: 0.47% · All testbenches verified with Icarus Verilog and NIST test vectors**

### Phase 2 — Blue Team (Trojan Detection)

Built a two-layer AI-powered detection pipeline that analyzes RTL designs for hardware Trojans without comparing against any golden reference.

- **Layer 1 — Heuristic Detector** (`heuristic_detector.py`): Offline regex-based pattern matching for magic constants, key-in-output paths, FSM stall guards, round reduction overrides, and suspicious signal names. Tested across all 70 blue-team releases (44 AES, 13 ETHMAC, 13 CV32E40P).
- **Layer 2 — AI Semantic Analyzer** (`detect_trojans.py`): Sends each RTL file to Claude via API with a security-expert system prompt. Returns structured JSON with exact line numbers, confidence levels, and Trojan type classification. Includes cross-reference pass for multi-file Trojans.
- **Batch Runner** (`run_all_detections.py`): Processes all 70 projects automatically with rate limiting and consolidated reporting.
